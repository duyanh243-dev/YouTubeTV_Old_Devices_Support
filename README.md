# Requirements & Setup

1. First, install the "app.revanced.android.gms_5.13.apk" file. This app runs as a background service to keep the main application running and prevent crashes or unexpected exits.
2. Install either the "YT_TV5.0.apk" or "YT_TV7.0.apk" file.
> *Note: "YT_TV5.0.apk" is for Android 5 and up. "YT_TV7.0.apk" is for Android 7 and up.*
3. Open the YouTube app for the first time. It is recommended to close and reopen the app to ensure the initialization process completes correctly.
4. Enjoy the app.
